## 3. Hard rules (all binding)

1. Scripture text matches the stated translation word for word; the reference and translation are on screen.
2. Lyrics only for songs owned or cleared by The Wait Culture.
3. One phrase per card; one or two emphasis words per phrase, no more.
4. Portrait line breaks are set by hand with "|" so no line ends on an orphan word.

**Studio rules (always apply)**
- Every text, logo, number and UI element is set in Remotion, never rendered by an AI model.
- All motion comes from `useCurrentFrame()`; timing is in seconds × fps; no CSS transitions, timers or `Math.random()`.
- Fonts are bundled locally and loaded with `@remotion/fonts`; nothing loads from the network at render time.
- No paid generation without an approved quote, and no skipped approval gates (storyboard, style frames, review cut).
- No real-person likeness without consent; no generated third-party logos or trademarks.

## 14. QA checklist

- ☐ `npm run lint` passes (ESLint + TypeScript).
- ☐ Every final passes `npm run qc`: resolution, fps, exact duration, BT.709, loudness and true peak.
- ☐ Hierarchy: one focal point per frame; text readable at phone size; contrast ≥ 4.5:1 for body text.
- ☐ Safe areas: nothing important within 5% of the edges; on 9:16, bottom 20% and right 12% clear.
- ☐ No orphan words on headlines; brand palette only; spelling and numbers match the brief.
- ☐ Every emphasis word appears in its phrase.
- ☐ Text checked word for word against the translation.
- ☐ Footer reference visible on every card; end card shows reference + translation.

**Pitfalls found during production**
- SVG `vector-effect: non-scaling-stroke` measures dashes in screen pixels, so evolvePath draw-ons came out broken. Underlines use path units instead.
- `<Freeze>` cannot show source frames past the composition end; SpeedRamp shifts a `<Sequence>` instead (tested: output 0.5 s = source 5.0 s).
- Long phrases in 16:9 ran to the strip edge on one line; phrases over 30 characters now break at the marked point.
- A cross-fade exit looked digital; paper strips are pulled away instead, with a 3-frame breath between cards.
